# Private Windows RC boundary

This candidate is a private, limited trial centered on dedicated public-window capture, offline OCR source text, timeline/history, and pause/recovery. Full-desktop capture remains unavailable. Real model understanding and unattended daily use are not certified.

Goal automation and synthetic model-chat dispatch are unavailable in the RC application composition. Conversation turn reads retain receipt identities/outcomes but withhold content and embedded goal contexts; historical goal inbox notices are projected as unavailable. Stored rows are never rewritten by these projections. New conversation-goal adoption is rejected before creation; goal activation, resume, global enable, background ticks and already-active legacy goals cannot advance. Original data, goal IDs/status, manual notes, receipt reads, pause and cancel remain available. Public goal details and positive completion claims are withheld rather than guessing legacy provenance. No recursive dependency feature or data migration is included.

The reusable kernel's ordinary unit tests remain separate from this RC policy. Default application composition and explicit RC tests verify the unavailable boundary, including direct engine use with the RC service. No user-facing or environment override is supplied.

Strict/local-only inference requires fresh supported native Ollama metadata with local-weight evidence and no remote indicators; its compatible /v1 interface is supported under the same check. Generic local providers and standalone llama.cpp are unavailable because their metadata does not prove that stock RPC offloading is absent. Existing configurations are retained. Prior Windows standalone-model runs are historical evidence, not acceptance of this candidate. Installed versions are unchanged until a separately authorized installation.

Private native acceptance, real rendered UI testing, final exact-head CI, repository merge authorization and any public hosting/deployment consequence remain separate gates.
